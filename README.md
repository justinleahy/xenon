# Xenon

Xenon is a Rust game engine project in its planning and foundation stage.

This codebase is AI assisted but NOT AI generated. All code will be written by humans. AI will only assist with understanding and guiding the development process.

Start here:

- [Engine charter](ENGINE_CHARTER.md)
- [Development phases](GAME_ENGINE_DEVELOPMENT_PHASES.md)

## Run the Sandbox

```bash
cargo run -p sandbox
```

The sandbox loads runtime settings from:

sandbox/config/runtime.toml
